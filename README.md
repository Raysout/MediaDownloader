# Media Downloader Pro

Современное десктопное приложение для ОС Windows на базе **Python 3** и **PyQt6**, предназначенное для загрузки, конвертации и каталогизации медиаконтента (видео и аудио) с популярных веб-платформ.

---

## Возможности

* 🎬 **Загрузка видео**:
  * Поддержка YouTube (включая Shorts), TikTok, а также множества других видеохостингов через ядро yt-dlp.
  * Выбор качества вплоть до 4K/1080p/720p с автоматическим объединением видео и аудиодорожек.
  * Поддержка как одиночных роликов, так и плейлистов/каналов.
* 🎵 **Загрузка музыки**:
  * Интеграция со Spotify (одиночные треки, альбомы и плейлисты с метаданными и оригинальными обложками).
  * Поддержка SoundCloud, YouTube Music и других аудио-сервисов.
  * Экспорт в форматы MP3 (до 320 kbps), FLAC, M4A, WAV, OPUS.
* 📦 **Менеджер очереди**:
  * Пакетное добавление медиа в очередь с индивидуальными настройками для каждой задачи.
  * Возможность ставить очередь на паузу и возобновлять загрузку.
* 📊 **Мониторинг активных загрузок**:
  * Детальный экран текущих процессов с отображением скорости, прогресса, размера и расчетного времени (ETA).
* 📋 **История загрузок**:
  * Каталог скачанных файлов с возможностью открытия в проводнике или воспроизведения в системном плеере.
* 🎨 **Темы оформления**:
  * Поддержка нескольких цветовых схем (Ocean Blue, Emerald Green, Cyberpunk Purple, Sunset Orange, Dark Graphite).

---

## Требования

* **ОС**: Windows 10 / 11 (64-bit)
* **Python**: версия 3.10 или новее
* **FFmpeg**: требуется для конвертации форматов и склейки видео со звуком в высоком разрешении.

## Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-аккаунт>/MediaDownloader.git
cd MediaDownloader
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv .venv
# В PowerShell:
.\.venv\Scripts\Activate.ps1
# В командной строке CMD:
.\.venv\Scripts\activate.bat
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Установка FFmpeg (автоматически)
В проект включен скрипт, загружающий портативный FFmpeg в локальную директорию `media_downloader/bin`:
```bash
python install_ffmpeg.py
```

### 5. Запуск приложения
```bash
python main.py
```

---

## Сборка автономного исполняемого файла (.exe)

Для сборки независимого исполняемого файла Windows с помощью PyInstaller выполните:

```bash
python build_exe.py
```

Готовый дистрибутив будет собран в директории `dist/MediaDownloader/` и готов к запуску без необходимости установленного интерпретатора Python.
