## 🌟 Ключевые возможности

### 🎥 Загрузка видео
* **YouTube & Shorts**: Загрузка роликов и шортсов в оригинальном качестве вплоть до **4K / 1080p 60fps** с автоматической склейкой видео и аудио дорожек через FFmpeg.
* **YouTube Плейлисты**: Пакетный анализ и выкачивание плейлистов целиком.
* **TikTok**: Быстрое сохранение видеороликов в HD качестве без водяных знаков.
* **Другие видеохостинги**: Универсальный парсер для VK Видео, Rutube, Vimeo, Dailymotion, Twitter (X) и других сервисов через ядро `yt-dlp`.
* **Гибкие форматы**: Сохранение в MP4, MKV или WEBM с выбором кодеков и битрейта.

### 🎵 Загрузка музыки и аудио
* **Spotify Metadata Matching**: Продвинутая система сопоставления метаданных Spotify (треки, альбомы, плейлисты) с официальными аудиопотоками в наивысшем битрейте.
* **Автоматические теги и обложки**: Вшивание в скачанные файлы ID3v2-тегов (исполнитель, альбом, трек, год) и оригинальных HD-обложек с помощью `mutagen`.
* **SoundCloud & YouTube Music**: Прямая загрузка треков, ремиксов и плейлистов.
* **Форматы экспорта**: MP3 (до 320 kbps), FLAC (Lossless), M4A (AAC), WAV, OPUS.

### ⚡ Производительность и многозадачность
* **Фоновая обработка (QThread)**: Интерфейс никогда не блокируется и не зависает — все операции парсинга, скачивания и конвертации выполняются в отдельных потоках.
* **Менеджер очереди**: Добавление произвольного количества задач в очередь, возможность приостановки (паузы) и возобновления в любой момент.
* **Мониторинг в реальном времени**: Экран активных загрузок с отображением динамической скорости, полосы прогресса, загруженного объема и расчетного времени завершения (ETA).
* **Атомарная история**: Локальный журнал загрузок с возможностью быстрого открытия файла в плеере или в проводнике Windows, а также автоочистка записей об удаленных файлах.

### 🎨 Премиальный пользовательский интерфейс
* Стильный темный дизайн в концепции **Material 3 / Modern Dark**.
* **5 динамических цветовых палитр**:

* Мгновенная вставка ссылок из буфера обмена (Win32 API без задержек и утечек дескрипторов).

## 🚀 Установка и запуск

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-аккаунт>/MediaDownloader.git
cd MediaDownloader
```

### Шаг 2. Создание виртуального окружения
```bash
python -m venv .venv
```

Активация в Windows PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
```
*(Или в классической командной строке CMD: `.\.venv\Scripts\activate.bat`)*

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 4. Установка портативного FFmpeg (в один клик)
В репозиторий встроен автозагрузчик, который скачивает и распаковывает официальную портативную сборку FFmpeg в папку `media_downloader/bin/`:
```bash
python install_ffmpeg.py
```
> [!NOTE]
> Если в вашей системе FFmpeg уже установлен и прописан в системную переменную `PATH`, приложение автоматически обнаружит его.

### Шаг 5. Запуск приложения
```bash
python main.py
```

## 📖 Архитектура

Приложение спроектировано по принципам чистой архитектуры:
* Презентационный уровень (`ui/`) изолирован от бизнес-логики.
* Взаимодействие между воркерами и интерфейсом построено на сигналах `pyqtSignal`.
* Корневые модули функционируют как фасады обратной совместимости.

Подробная диаграмма компонентов и описание потокобезопасности приведены в [ARCHITECTURE.md](ARCHITECTURE.md).
